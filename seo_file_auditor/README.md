# SEO File Auditor MVP v0.5

Локальный SEO-инструмент для проверки внутренних файлов сайта, технических дублей и базовых технических ошибок.

## Что нового в v0.5

- добавлена галочка в разделе **Технические дубли**: «Подсвечивать отличия URL в строках отчёта»
- в таблице дублей теперь можно визуально сравнивать стартовый и финальный URL
- отличающиеся фрагменты подсвечиваются жёлтым: протокол, `www`, слэш, `index.php`, параметры и другие изменения
- подсветка также работает для пар похожих страниц
- обычная таблица без подсветки остаётся доступной внутри раскрывающегося блока

## Что было добавлено в v0.4

- обновлён интерфейс: более понятный, аккуратный и человекочитаемый
- точечные инструменты вынесены в боковое меню
- улучшены отчёты: добавлены быстрые выводы, приоритетные задачи и более понятные таблицы
- сохранена главная общая проверка сайта

## Разделы сервиса

### 1. Главная проверка сайта
Проверяется:
- robots.txt
- sitemap.xml / sitemap_index.xml / wp-sitemap.xml
- URL из sitemap
- статус-коды страниц
- title / description / h1 / canonical / meta robots
- базовое поведение сервера
- экспорт CSV

### 2. robots.txt
Можно:
- проверить файл по ссылке
- загрузить файл вручную
- вставить текст robots.txt
- получить разбор User-agent / Allow / Disallow / Sitemap / Crawl-delay / Clean-param
- посмотреть построчную таблицу директив
- проверить список URL по директивам robots.txt для Googlebot, YandexBot и `*`
- скачать CSV

### 3. sitemap.xml
Можно:
- проверить файл по ссылке
- загрузить XML-файл
- вставить XML вручную
- определить тип: urlset / sitemap_index / invalid / unknown
- проверить URL и вложенные sitemap
- увидеть дубли `<loc>`
- найти HTTP URL внутри sitemap
- проверить разные хосты, относительные URL и проблемные `lastmod` / `priority`
- проверить статус-коды URL из sitemap
- скачать CSV

### 4. .htaccess
Файл `.htaccess` нельзя получить публично с сайта, поэтому его нужно загрузить или вставить вручную.

Проверяется:
- RewriteEngine
- RewriteCond / RewriteRule
- HTTP → HTTPS
- www / non-www
- потенциальные циклические редиректы
- временные 302-редиректы
- защита `.env`, `wp-config.php`, `composer.json`, `.git`
- Options -Indexes
- gzip / brotli / deflate
- кэширование статики
- ErrorDocument 404
- построчный разбор правил

Важно: анализ `.htaccess` эвристический. Сервис не исполняет Apache-конфигурацию, а ищет типовые SEO-риски.

### 5. Технические дубли
Проверяются варианты:
- http / https
- www / non-www
- `/` и без `/`
- `/index.php`
- `/index.html`
- `/index.htm`
- URL с параметрами
- URL с фрагментом `#`
- дополнительные URL из списка

Сервис показывает:
- финальный URL
- статус-коды
- цепочку редиректов
- количество хопов
- петли редиректов
- возможные дубли без редиректа
- похожие финальные страницы по title / canonical / тексту
- подсветку отличий между URL в одной строке отчёта

## Запуск на Mac

```bash
cd ~/Downloads/seo_file_auditor
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Открыть в браузере:

```text
http://localhost:8501
```

## Запуск на Windows PowerShell

```powershell
cd Downloads\seo_file_auditor
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

## Примечания

- Инструмент работает локально и ничего не отправляет на сторонние сервисы.
- Для больших сайтов начинайте с лимита 50–100 URL.
- Проверка sitemap и технических дублей делает реальные HTTP-запросы к сайту, поэтому не ставьте слишком большие лимиты без необходимости.
